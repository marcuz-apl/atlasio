ACCESS

Profiles —

Administrator and Data Manager accounts sign in with their own passwords and change the initial one at first use. Managed profiles cover viewers, importers, and reviewers; custom keys are stored as hashes and shown once.

Revoke a key and it stops working on the next request. Rotate a demo key and the sign-in gate picks it up immediately.

RECOVERY

Backups —

Each backup pairs a PostgreSQL custom-format dump with a manifest, its SHA-256 checksum, and record counts. With local object storage, original files are copied into the same archive.

Verify restores the archive into a scratch database and compares counts. Restore takes a fresh pre-restore backup first, then requires typed confirmation.

    DISCLAIMER

    Data stewardship matters.

    Catalog counts reflect records available to your role. Items marked “Planned” are not represented in the current catalog. Map positions are shown only when source coordinates have passed the configured review workflow.

    Check source licenses and coordinate provenance before using data in operational decisions.

    POSITION

    Pick a position on the map

    Click the map to set the source position. A pick is explicit: it fills X/Y and sets the source CRS to EPSG:4326. For a native CRS, cancel and type the source values instead.
