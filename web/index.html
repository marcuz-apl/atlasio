ATLASIO / ADMINISTRATION

Operations

—

Access profiles, database backups, and the audit trail behind every governed change.

Maintenance in progress. Writes are blocked while a restore runs. Only Administrators can sign in until it finishes.

ACCESS

Profiles —

Administrator and Data Manager keys come from the server environment. Managed profiles cover viewers, importers, and reviewers; custom keys are stored as hashes and shown once.

Revoke a key and it stops working on the next request. Rotate a demo key and the sign-in gate picks it up immediately.

RECOVERY

Backups —

Each backup pairs a PostgreSQL custom-format dump with a manifest, its SHA-256 checksum, and record counts. With local object storage, original files are copied into the same archive.

Verify restores the archive into a scratch database and compares counts. Restore takes a fresh pre-restore backup first, then requires typed confirmation.

DISCLAIMER

Data stewardship matters.
