# Atlasio

Atlasio is a planned governed subsurface data workspace. It aims to help teams stage, review, publish, and find technical data, with a map for discovery and inspection. Source files, provenance, dataset versions, permissions, and coordinate integrity are central to the product.

The project is currently at the requirements stage; there is no application to run yet. The first implementation slice will take a well package through staging, quality checks, review, publication, search, and map display. The core is intended for global use. Libya is the first pilot context, not a fixed product assumption.
